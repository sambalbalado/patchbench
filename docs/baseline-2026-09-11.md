# GPT-5 Mini baseline — 2026-09-11

PatchBench's first live baseline ran all 24 bundled cases against `gpt-5-mini` with prompt
`review-v1`. The repository was at commit `81bd6ce` before this report was added. The corpus was
balanced between 12 defect-introducing patches and 12 safe patches.

The complete machine-readable result is in
[`results/gpt-5-mini-review-v1-baseline-2026-09-11.json`](../results/gpt-5-mini-review-v1-baseline-2026-09-11.json).

## Incorrect answers versus execution failures

There were no API, timeout, parsing, or schema-validation failures. Every seeded bug was detected,
and every positive finding used the correct file and an accepted line. The model's incorrect
detection answers were four false positives on safe changes:

- `safe_json_deserialization`
- `safe_membership_refactor`
- `safe_path_validation`
- `safe_redacted_logging`

The model also used a category different from the expected label on six positive cases:

- `authorization_bypass`
- `cache_key_omits_locale`
- `data_loss_write_mode`
- `missing_await`
- `secret_logging`
- `weak_token_generation`

## Interpretation and next improvement

The baseline establishes that the current reviewer is sensitive to real defects and strong at
localizing them, but it is not yet selective enough on safe changes. Category naming is also too
open-ended for stable comparisons.

The next roadmap task is bounded concurrency with per-case failure isolation. The baseline had no
execution failures, but its sequential requests took about 6 minutes 38 seconds, so bounded
parallelism can reduce wall-clock time while preserving a result for every case. A later prompt and
label-alignment pass should target the four false positives and normalize category vocabulary.

That follow-up was completed in the
[2026-09-20 label audit](label-audit-2026-09-20.md). The historical metrics above remain tied to
`review-v1`; future live runs use the constrained `review-v2` category contract.

## Cost-control procedure

The run started with one case as a smoke check. That request cost an estimated $0.0014135. The
remaining 23 cases continued only after that value was verified, and the smoke result was reused in
the final aggregate rather than requested twice.
